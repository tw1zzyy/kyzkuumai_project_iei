# 🐎 Kyz Kuumai Runner

**Kyz Kuumai Runner** — это 2D браузерная игра в жанре **endless runner**, вдохновлённая традиционной кыргызской конной игрой **Kyz Kuumai**.
Игрок управляет девушкой-наездницей, которая скачет на лошади по бесконечному ландшафту кыргызских гор, перепрыгивая препятствия.

Игра создана с использованием **чистого JavaScript, HTML и CSS**, без игровых движков.

---

# 🎮 Gameplay

Игрок управляет **кыргызской девушкой на лошади**, которая автоматически бежит вперёд.

Цель игры:

* перепрыгивать препятствия
* избегать столкновений
* набрать максимальное количество очков

Игра продолжается бесконечно, пока персонаж не столкнётся с препятствием.

# 🏇 О традиционной игре Kyz Kuu

**Kyz Kuu** — это традиционная конная игра народов Центральной Азии.

Правила:

* парень должен догнать девушку на лошади
* если он догоняет её — может поцеловать
* если нет — на обратном пути девушка догоняет его и бьёт камчой

Эта игра символизирует **ловкость, скорость и мастерство верховой езды**.
